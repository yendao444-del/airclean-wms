API 1: ĐĂNG NHẬP LẤY TOKEN
================================================================================
URL:     POST <BaseURL>/auth/token
Ví dụ:   https://testapi.meinvoice.vn/api/v3/auth/token

Body Parameter:
{
    "appid": "chuỗi ký tự được MISA cung cấp",
    "taxcode": "Mã số thuế",
    "username": "tài khoản đăng nhập hệ thống MISA",
    "password": "Mật khẩu đăng nhập hệ thống MISA"
}

Response (thành công):
{
    "Success": true,
    "ErrorCode": null,
    "Errors": [],
    "Data": "eyJhbGciOiJIUzI1NiIs... (JWT Token)",
    "CustomData": null
}

** LƯU Ý QUAN TRỌNG **
- Token có thời hạn 15 ngày
- Khi token hết hạn, API trả về ErrorCode = "TokenExpiredCode"
- Gọi API refreshtoken để gia hạn:
  + URL: POST <BaseURL>/auth/refreshtoken
  + Body: Token cũ đã hết hạn
  + Response: Token mới

Mã lỗi thường gặp:
- InvalidAppID     → Sai thông tin AppID
- InactiveAppID    → Ứng dụng bị ngừng theo dõi
- UnAuthorize      → Sai thông tin đăng nhập

API 8: KIỂM TRA TRẠNG THÁI HÓA ĐƠN (theo TransactionID)
================================================================================
URL (Không mã):  POST <BaseURL>/itg/invoicepublished/invoicestatus
URL (Có mã):     POST <BaseURL>/code/itg/invoicepublished/invoicestatus

Body: List Mã tra cứu (TransactionID)
["1VUQHQ48_", "KDU0HQWAB"]

Response (Data):
{
    "TransactionID": "1VUQHQ48_",
    "PublishStatus": 1,            // Trạng thái phát hành
    "ReferenceType": 0,            // 0=gốc, 1=thay thế, 2=điều chỉnh
    "InvoiceCode": null,           // Mã CQT (nếu HĐ có mã)
    "SendTaxStatus": 2,            // Xem bảng giá trị bên dưới
    "IsSentEmail": false,          // Đã gửi email chưa
    "IsDelete": false,             // Đã hủy chưa
    "DeletedDate": null,
    "DeletedReason": null,
    "ReceivedStatus": 0            // 0=chưa nhận, 1=đã nhận
}

Bảng giá trị SendTaxStatus:
- HĐ Không có mã: 0=chưa gửi CQT, 1=đã gửi, 2=CQT tiếp nhận, 3=CQT không tiếp nhận, 4=gửi lỗi
- HĐ Có mã:       0=chờ cấp mã, 1=gửi lỗi, 2=đã cấp mã, 3=từ chối cấp mã, 4=gửi lỗi

================================================================================
3.1 OriginalInvoiceData (Thông tin chung hóa đơn)
================================================================================

--- THÔNG TIN CƠ BẢN ---
RefID                  : string   - ID hóa đơn trên Client App (UUID)
InvSeries              : string   - Ký hiệu hóa đơn (VD: "1C22MMT")
InvoiceName            : string   - Tên hóa đơn
InvDate                : DateTime - Ngày hóa đơn (VD: "2022-10-10")
CurrencyCode           : string   - Mã tiền tệ (VD: "VND")
ExchangeRate           : decimal  - Tỷ giá (VND = 1.0)
PaymentMethodName      : string   - Hình thức thanh toán (VD: "Tiền mặt", "TM/CK")
InvoiceNote            : string   - Ghi chú hóa đơn
InvoiceTemplateID      : Guid     - ID mẫu hóa đơn

--- THÔNG TIN NGƯỜI BÁN ---
SellerLegalName        : string   - Tên người bán
SellerTaxCode          : string   - MST người bán
SellerAddress          : string   - Địa chỉ người bán
SellerPhoneNumber      : string   - ĐT người bán
SellerEmail            : string   - Email người bán
SellerBankAccount      : string   - Số TK ngân hàng
SellerBankName         : string   - Tên ngân hàng

PHƯƠNG THỨC KHUYẾN NGHỊ: MÁY TÍNH TIỀN (MTT)
================================================================================

Lý do chọn MTT:
✅ Không cần ký số (không cần USB token, không cần cài tool)
✅ 1 bước duy nhất: Tạo + Phát hành cùng lúc
✅ Phù hợp cho hệ thống bán hàng tự động
✅ HĐ được MISA ký và gửi CQT tự động

WORKFLOW HOÀN CHỈNH:
====================

1. Lấy Token
   POST https://api.meinvoice.vn/api/v3/auth/token
   → Lưu token, hạn 15 ngày

2. Lấy danh sách mẫu HĐ (lần đầu)
   GET https://api.meinvoice.vn/integration/invoice/templates?invoiceWithCode=true&ticket=false&year=2026
   → Lấy InvSeries phù hợp (VD: "1C26MMT")

3. Xuất hóa đơn (cho từng đơn hàng hoặc hàng loạt)
   POST https://api.meinvoice.vn/api/v3/code/itg/invoice-calculating/invoiceandpublish
   Body: [{ OrgInvoiceData: {..., IsInvoiceCalculatingMachine: true}, IsSendEmail: true, ReceiverEmail: "..." }]
   → Nhận TransactionID, InvNo, InvCode

4. Kiểm tra trạng thái (nếu cần)
   POST https://api.meinvoice.vn/api/v3/code/itg/invoicepublished/invoicestatus
   Body: ["TransactionID"]

5. Tải HĐ PDF/XML (nếu cần)
   POST https://api.meinvoice.vn/api/v3/code/itg/invoice-calculating-published/download?downloadDataType=PDF
   Body: ["TransactionID"]

6. Gửi email HĐ (nếu chưa gửi lúc phát hành)
   POST https://api.meinvoice.vn/api/v3/itg/emails

7. Hủy HĐ (nếu cần)
   POST https://api.meinvoice.vn/api/v3/itg/invoicepublished/cancel
   Body: { TransactionID: "...", InvNo: "...", RefDate: "...", CancelReason: "...", InvoiceType: 10 }
