CẤU TRÚC DB ĐÃ SẴN SÀNG (Prisma schema):
──────────────────────────────────────────

- refInvoiceId        → Liên kết chuỗi HĐ (parent → child chain)
- adjustmentType      → 'adjustment' | 'replacement'
- adjustmentReason    → Lý do bắt buộc theo CQT
- isTaxDeductedByPlatform → Cờ sàn đã khấu trừ thuế
- platformTaxRate     → 0.015 (1.5%)
- platformTaxAmount   → Số tiền thuế sàn đã trừ
- invoiceType         → pos_receipt | b2b | ecommerce_export
- xmlFilePath         → Path file XML gốc
- pdfFilePath         → Path file PDF
- templateCode        → Mẫu số HĐ
- invoiceSeries       → Ký hiệu HĐ
