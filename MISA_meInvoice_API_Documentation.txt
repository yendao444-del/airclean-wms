1. GIỚI THIỆU
================================================================================

Tài liệu này dành cho các nhà phát triển ứng dụng muốn tích hợp vào hệ thống 
hóa đơn điện tử đầu ra của MISA – MISA meInvoice. Tài liệu mô tả các đầu API 
phục vụ việc tích hợp kết nối các hệ thống khác vào dịch vụ hóa đơn điện tử 
đầu ra của MISA.

--------------------------------------------------------------------------------
1.1. Thông tin cần trước khi kết nối
--------------------------------------------------------------------------------

- app_id: Nhà phát triển có nhu cầu tích hợp với MISA meInvoice cần đăng ký 
  với MISA để được cung cấp qua nhân viên kinh doanh/Tổng đài/Live Chat.

--------------------------------------------------------------------------------
1.2. Mô tả URL, Endpoint của các chức năng
--------------------------------------------------------------------------------

Base URL:
  - Môi trường Test:    https://testapi.meinvoice.vn/api/integration
  - Môi trường Product: https://api.meinvoice.vn/api/integration

Giao diện web:
  - Môi trường Test:    https://testapp3.meinvoice.vn
  - Môi trường Product: https://app3.meinvoice.vn

Danh sách Endpoint:
+-----+------------------------------------------+-------------------------------------------+
| STT | Chức năng                                | Endpoint                                  |
+-----+------------------------------------------+-------------------------------------------+
|  1  | Lấy token xác thực                       | {BaseURL}/auth/token                      |
|  2  | Lấy danh sách mẫu hóa đơn               | {BaseURL}/invoice/templates               |
|  3  | Xem hóa đơn trước khi phát hành (nháp)  | {BaseURL}/invoice/unpublishview           |
|  4  | Phát hành hóa đơn/vé điện tử             | {BaseURL}/invoice                         |
|  5  | Xem hóa đơn đã phát hành                | {BaseURL}/invoice/publishview             |

--------------------------------------------------------------------------------
1.3. Mô tả cấu trúc của API MeInvoice
--------------------------------------------------------------------------------

Kết quả trả về luôn có định dạng JSON:

{
    "success": true/false,
    "errorCode": "Mã lỗi",
    "descriptionErrorCode": "Mô tả lỗi",
    "createInvoiceResult": "Kết quả tạo hóa đơn",
    "publishInvoiceResult": "Kết quả phát hành hóa đơn",
    "errors": "Danh sách mô tả lỗi",
    "data": "Dữ liệu phản hồi",
    "customData": "thông tin khác"
}

--------------------------------------------------------------------------------
1.4. Hướng dẫn xử lý kết quả của API (Response)
--------------------------------------------------------------------------------

Khi nhận kết quả, cần kiểm tra:
1. Trường "Success": Nếu false, kiểm tra "ErrorCode" và "Errors".
2. Trường "ErrorCode": Nếu có mã lỗi, đối chiếu với bảng mã lỗi (Mục 14).
3. Với API phát hành: Kiểm tra thêm "createInvoiceResult" và 
   "publishInvoiceResult" trong "Data".

--------------------------------------------------------------------------------
1.5. Các bước thực hiện
--------------------------------------------------------------------------------

Bước 1: Đăng ký app_id với MISA.
Bước 2: Đăng nhập vào hệ thống meInvoice (test hoặc product) để thiết lập:
         - Thiết lập ký số
         - Lập tờ khai
         - Thiết lập mẫu hóa đơn
Bước 3: Gọi API lấy token (Mục 2).
Bước 4: Gọi API lấy danh sách mẫu hóa đơn (Mục 3) để lấy thông tin cần thiết 
         (InvSeries, IsSendSummary).
Bước 5: Xem trước hóa đơn trước khi phát hành (Mục 4) - Tùy chọn.
Bước 6: Phát hành hóa đơn:
         - Nếu sử dụng USB Token: Thực hiện theo Mục 5
         - Nếu sử dụng HSM/eSign nâng cao: Thực hiện theo Mục 6
Bước 7: Xem hóa đơn đã phát hành (Mục 7).
Bước 8: Tải hóa đơn PDF/XML (Mục 8).
Bước 9: Kiểm tra trạng thái hóa đơn (Mục 11).
Bước 10: Điều chỉnh/Thay thế hóa đơn nếu cần (Mục 9).

--------------------------------------------------------------------------------
1.6. Những lưu ý trước khi tích hợp (Hiểu thêm về hóa đơn và API)
--------------------------------------------------------------------------------

* Dữ liệu RefID (Mã tham chiếu) của mỗi hóa đơn là duy nhất trên hệ thống 
  Client. Mỗi RefID chỉ được sử dụng phát hành 1 lần duy nhất.

* SignType (Loại ký số):
  - 1: Ký số bằng USB Token/File (Client ký) - Quy trình 3 bước (5.1→5.2→5.3)
  - 2: Ký số bằng HSM/Cloud (MISA Cloud ký) - Có hiển thị CKS trên hóa đơn
  - 5: Không ký (Dành cho máy tính tiền MTT hoặc vé) - Không hiển thị CKS

* Về Hóa đơn Máy tính tiền (MTT):
  - Sử dụng SignType = 5
  - Cần thiết lập IsInvoiceCalculatingMachine = true trong InvoiceData
  - Ký hiệu mẫu hóa đơn MTT khác với hóa đơn thường

* Môi trường Test:
  - URL test: https://testapp3.meinvoice.vn/
  - URL API test: https://testapi.meinvoice.vn/api/integration
  - Kiểm tra bảng kê: Menu Báo cáo/Bảng kê hóa đơn đã sử dụng

* Môi trường Product:
  - URL product: https://app3.meinvoice.vn
  - URL API product: https://api.meinvoice.vn/api/integration

* Tải Postman Collection mẫu:
  https://drive.usercontent.google.com/u/0/uc?id=1MzYumxqskC7Ze39unho60YRg3UXIerTR&export=download

2. API LẤY MÃ KẾT NỐI (GET TOKEN)
================================================================================

Sử dụng khi kết nối với ứng dụng MISA meInvoice để lấy token phục vụ cho 
các hàm xử lý nghiệp vụ.

- URL: {BaseURL}/auth/token
  + Test:    https://testapi.meinvoice.vn/api/integration/auth/token
  + Product: https://api.meinvoice.vn/api/integration/auth/token
- Method: POST
- Header: Content-Type: application/json

Request Body:
{
    "appid": "{AppID}",
    "taxcode": "{Mã số thuế}",
    "username": "{Tài khoản meInvoice}",
    "password": "{Mật khẩu meInvoice}"
}

Response:
{
    "Success": <false/true>,
    "Data": "<Dữ liệu token trả về>",
    "ErrorCode": "<Trống hoặc Mã lỗi>",
    "Errors": "",
    "CustomData": ""
}

Ghi chú:
- Token có hiệu lực trong 14 ngày.
- Khuyến nghị: Gọi lại sau mỗi 7 ngày để làm mới token.
- Mã lỗi: Xem Mục 14.

Ví dụ cURL:
curl --location 'https://testapi.meinvoice.vn/api/integration/auth/token' \
--header 'Content-Type: application/json' \
--data-raw '{
    "appid": "MISA cung cấp khi đăng ký tích hợp API",
    "taxcode": "{Mã số thuế}",
    "username": "{Tài khoản}",
    "password": "{Mật khẩu}"
}'

3. API LẤY DANH SÁCH MẪU HÓA ĐƠN / MẪU VÉ
================================================================================

- URL: {BaseURL}/invoice/templates
  + Test:    https://testapi.meinvoice.vn/api/integration/invoice/templates
  + Product: https://api.meinvoice.vn/api/integration/invoice/templates
- Method: GET
- Header: Authorization: Bearer {token}

Query Parameters:
  - invoiceWithCode (bool): true = Lấy mẫu hóa đơn có mã của cơ quan thuế
  - ticket (bool): true = Lấy danh sách mẫu vé

Response:
{
    "Success": <false/true>,
    "Data": "<Danh sách mẫu>",
    "ErrorCode": "<Trống hoặc Mã lỗi>",
    "Errors": "",
    "CustomData": ""
}

Ghi chú:
- Cần lưu lại InvSeries (Ký hiệu) và IsSendSummary để truyền vào dữ liệu 
  phát hành.
- Xem mô tả đối tượng Template tại Mục 13.1.

Ví dụ cURL:
curl --location 'https://testapi.meinvoice.vn/api/integration/invoice/templates?invoiceWithCode=true&ticket=false' \
--header 'Authorization: Bearer {chuỗi token lấy ở API GetToken}'

--------------------------------------------------------------------------------

- URL local: http://localhost:8282/ (hoặc port do SignService cấu hình)
- Method: POST

Request Body:
{
    "PinCode": "xxxxxxx",    // Mật khẩu của chứng thư số (CKS)

}

Response:
{
    "Status": 200,
    "PayLoad": "",       // Chuỗi XML đã được ký số
    "Message": null      // Thông báo lỗi nếu có
}

13. MÔ TẢ ĐỐI TƯỢNG CỦA HÓA ĐƠN
================================================================================

--------------------------------------------------------------------------------
13.1. Template (Mẫu hóa đơn)
--------------------------------------------------------------------------------

Dữ liệu trả về từ API lấy danh sách mẫu hóa đơn (Mục 3):
  - InvSeries: Ký hiệu hóa đơn (VD: "1C25MLT", "5C25MMB")
  - TemplateName: Tên mẫu hóa đơn
  - InvoiceTypeID: Loại hóa đơn
  - IsSendSummary: Có gửi bảng tổng hợp hay không
  - IsInvoiceCode: Hóa đơn có mã CQT hay không

--------------------------------------------------------------------------------
13.2. (Thông tin người bán - tự động theo MST)
--------------------------------------------------------------------------------

Thông tin người bán được lấy tự động theo MST đã đăng ký trên hệ thống MISA.

--------------------------------------------------------------------------------
13.3. InvoiceData (Dữ liệu hóa đơn)
--------------------------------------------------------------------------------

Đối tượng JSON chứa toàn bộ thông tin hóa đơn. Các trường chính:

THÔNG TIN CHUNG:
  - RefID (string, bắt buộc): Mã tham chiếu duy nhất từ hệ thống Client
  - InvSeries (string, bắt buộc): Ký hiệu hóa đơn (lấy từ API mẫu)
  - InvDate (string, bắt buộc): Ngày hóa đơn (định dạng: "yyyy-MM-dd")
  - CurrencyCode (string): Mã tiền tệ (VD: "VND", "USD")
  - ExchangeRate (decimal): Tỷ giá (mặc định 1.0 nếu VND)
  - PaymentMethodName (string): Phương thức thanh toán 
    ("TM" = Tiền mặt, "CK" = Chuyển khoản, "TM/CK" = cả hai)
  - IsInvoiceCalculatingMachine (bool): true = Hóa đơn máy tính tiền (MTT)

THÔNG TIN NGƯỜI MUA:
  - BuyerLegalName (string): Tên đơn vị mua hàng
  - BuyerTaxCode (string): Mã số thuế người mua
  - BuyerAddress (string): Địa chỉ người mua
  - BuyerFullName (string): Họ tên người mua hàng
  - BuyerEmail (string): Email người mua
  - BuyerPhoneNumber (string): Số điện thoại người mua
  - BuyerCode (string): Mã khách hàng
  - BuyerBankAccount (string): Số tài khoản ngân hàng người mua
  - BuyerBankName (string): Tên ngân hàng người mua

THÔNG TIN TIỀN TỆ - TỔNG CỘNG:
  - TotalSaleAmountOC (decimal): Tổng tiền hàng trước thuế (nguyên tệ)
  - TotalSaleAmount (decimal): Tổng tiền hàng trước thuế (quy đổi)
  - TotalAmountWithoutVATOC (decimal): Tổng tiền chưa có thuế (nguyên tệ)
  - TotalAmountWithoutVAT (decimal): Tổng tiền chưa có thuế (quy đổi)
  - TotalVATAmountOC (decimal): Tổng tiền thuế GTGT (nguyên tệ)
  - TotalVATAmount (decimal): Tổng tiền thuế GTGT (quy đổi)
  - TotalDiscountAmountOC (decimal): Tổng tiền chiết khấu (nguyên tệ)
  - TotalDiscountAmount (decimal): Tổng tiền chiết khấu (quy đổi)
  - TotalAmountOC (decimal): Tổng tiền thanh toán (nguyên tệ)
  - TotalAmount (decimal): Tổng tiền thanh toán (quy đổi)
  - TotalAmountInWords (string): Số tiền bằng chữ

DANH SÁCH CHI TIẾT:
  - OriginalInvoiceDetail (array): Danh sách hàng hóa/dịch vụ (Mục 13.4)
  - TaxRateInfo (array): Tổng hợp thuế suất (Mục 13.5)
  - OtherInfo (array): Thông tin khác (Mục 13.6)
  - FeeInfo (array): Phí khác (Mục 13.7)
  - OptionUserDefined (object): Thiết lập người dùng hiển thị thập phân (Mục 13.9)
  - ClockInfos (array): Thông tin đồng hồ (cho hóa đơn điện/nước)

THÔNG TIN ĐIỀU CHỈNH/THAY THẾ (chỉ dùng khi điều chỉnh/thay thế):
  - OrgInvNo (string): Số hóa đơn gốc
  - OrgInvDate (string): Ngày hóa đơn gốc
  - InvoiceNote (string): Lý do điều chỉnh/thay thế
  - OriginalInvoiceID (string): ID hóa đơn gốc trên MISA
  - InvoiceType (int): 1=Gốc, 3=Thay thế, 5=Điều chỉnh

--------------------------------------------------------------------------------
13.4. OriginalInvoiceDetail (Dữ liệu dòng hàng hóa/dịch vụ)
--------------------------------------------------------------------------------

Mỗi dòng hàng hóa/dịch vụ trong hóa đơn:
  - ItemType (int): Loại dòng (1=Hàng hóa/dịch vụ, 2=Ghi chú, 3=Chiết khấu)
  - LineNumber (int): Số thứ tự dòng
  - SortOrder (int): Thứ tự sắp xếp
  - ItemCode (string): Mã hàng hóa/dịch vụ
  - ItemName (string, bắt buộc): Tên hàng hóa/dịch vụ
  - UnitName (string): Đơn vị tính
  - Quantity (decimal): Số lượng
  - UnitPrice (decimal): Đơn giá
  - DiscountRate (decimal): Tỷ lệ chiết khấu (%)
  - DiscountAmountOC (decimal): Tiền chiết khấu (nguyên tệ)
  - DiscountAmount (decimal): Tiền chiết khấu (quy đổi)
  - AmountOC (decimal): Thành tiền (nguyên tệ)
  - Amount (decimal): Thành tiền (quy đổi)
  - AmountWithoutVATOC (decimal): Tiền chưa thuế (nguyên tệ)
  - AmountWithoutVAT (decimal): Tiền chưa thuế (quy đổi)
  - VATRateName (string): Thuế suất (VD: "0%", "5%", "8%", "10%", "KTH", "KKKNT")
    + "KTH": Không tính thuế
    + "KKKNT": Không kê khai nộp thuế
  - VATAmountOC (decimal): Tiền thuế GTGT (nguyên tệ)
  - VATAmount (decimal): Tiền thuế GTGT (quy đổi)

--------------------------------------------------------------------------------
13.5. TaxRateInfo (Tổng hợp thuế suất)

  - VATRateName (string): Thuế suất
  - AmountWithoutVATOC (decimal): Tổng tiền chưa thuế (nguyên tệ)
  - AmountWithoutVAT (decimal): Tổng tiền chưa thuế (quy đổi)
  - VATAmountOC (decimal): Tổng tiền thuế (nguyên tệ)
  - VATAmount (decimal): Tổng tiền thuế (quy đổi)

15. CÂU HỎI THƯỜNG GẶP (FAQ)
================================================================================

1. Nếu gặp lỗi DuplicateInvoiceRefID thì cần làm gì?
   Trả lời: Với mã lỗi này nguyên nhân là RefID của hóa đơn đang phát hành 
   bị trùng với 1 RefID của hóa đơn đã được phát hành trước đó. Khi gặp mã 
   lỗi này thì trong response sẽ trả ra thông tin của hóa đơn bị trùng đã 
   được phát hành ở hệ thống MISA. Client có thể kiểm tra và cập nhật nếu 
   hóa đơn đó đã được phát hành nhưng client chưa ghi nhận thành công.

2. Nếu gặp mã lỗi InvoiceNumberNotCotinuous hoặc InvoiceDuplicated thì 
   cần làm gì?
   Trả lời: Với hai mã lỗi này thì Client thực hiện phát hành lại hóa đơn 
   đang phát hành tới khi thành công (gọi lại API phát hành).
